# Distributed Databases 

---

## Overview

This project explores different approaches to implementing distributed systems with various databases:

1. **Task 1**: Web counter with 4 backend options (In-Memory, File, PostgreSQL, Hazelcast)
2. **Task 2**: PostgreSQL-specific implementation with detailed testing
3. **Task 3**: Hazelcast distributed counter with CP subsystem and fault tolerance testing
4. **Task 4**: MongoDB database operations and performance testing with web counter
5. **Task 5**: Apache Cassandra 3-node cluster setup and configuration
6. **Task 6**: Performance comparison of all implementations under concurrent load
7. **Task 7**: MongoDB performance testing with varying workloads and configurations
Each task demonstrates different trade-offs between **performance**, **consistency**, and **fault tolerance**.
